Petualangan untuk tertawa

O Curioso adalah anak laki-laki yang tak pernah berhenti bertanya "kenapa?". Saat Raja Pemarah mencuri Tawa Agung dan kerajaan menjadi kelabu, ia berangkat bertualang bersama anjing setianya.

Melompat, lompat ganda, memanjat tangga, memantul di pegas, dan menaiki platform yang bergerak. Temukan tawa yang hilang, raih hingga tiga bintang per level, dan hadapi bos dengan serangan khasnya.

Dibuat untuk seluruh keluarga

  • Anjingnya tidak pernah mati

    Sahabat O Curioso selalu aman. Tanpa kekerasan dan tanpa adegan menakutkan.

  • Kontrol untuk semua

    Tombol atau joystick, mode kidal, dan tombol besar untuk tangan kecil.

  • Main tanpa internet

    Petualangan berjalan offline: di rumah, di mobil, atau saat bepergian.

  • Iklan hanya jika dipilih

    Sejak versi 14, iklan hanya muncul saat pemain memilih menontonnya untuk mendapat hadiah.

  • Tanpa pembelian

    Sejak versi 14, game ini tidak memiliki pembelian dengan uang sungguhan.

  • Selalu ada yang baru

    Tantangan harian, mode Survivor, event musiman, dan toko kostum.

Pertanyaan umum

Apakah game ini gratis?

Ya. Game ini bisa diunduh gratis di Google Play. Koin didapat dengan bermain atau, jika pemain mau, dengan menonton iklan.

Di perangkat apa game ini berjalan?

Di ponsel dan tablet Android dengan Android 7.0 atau lebih baru.

Game ini dalam bahasa apa?

Game ini dalam bahasa Inggris dan Portugis. Situs web ini tersedia dalam banyak bahasa.

Apakah perlu internet?

Tidak. Kamu bisa bermain offline. Internet hanya dipakai untuk iklan opsional dan papan peringkat Google Play Game.

Apakah aman untuk anak-anak?

Ya. Game ini tidak meminta data pribadi, tidak memiliki akun, dan iklannya sesuai untuk anak-anak serta tidak dipersonalisasi. Baca kebijakan privasi untuk detailnya.
