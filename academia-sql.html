SQL para jogos

Constrói uma tabela classificativa a partir dos resultados de várias rondas. Os dados do exercício são fictícios.

DadosFiltrarOrdenarAgruparProjetoQuestionário

Preparar os dados

Abre uma sessão SQLite nova com sqlite3 :memory: e cola este bloco uma só vez. Os dados duram até saíres da sessão. Executa depois uma consulta de cada vez.

CREATE TABLE rondas (
  jogador TEXT NOT NULL,
  nivel INTEGER NOT NULL,
  pontos INTEGER NOT NULL
);
INSERT INTO rondas (jogador, nivel, pontos) VALUES
  ('Lia', 1, 120), ('Lia', 2, 80),
  ('Noa', 1, 95), ('Noa', 2, 120),
  ('Teo', 1, 120), ('Teo', 2, 70);

1. Selecionar e filtrar linhas

SELECT escolhe as colunas. FROM indica a tabela a consultar. WHERE mantém as linhas que cumprem a condição.

SELECT jogador, pontos
FROM rondas
WHERE nivel = 2 AND pontos >= 80;

Exercício. Mostra as rondas do nível 2 com pelo menos 100 pontos.

Solução comentada

Troca 80 por 100. Só Noa satisfaz as duas condições, com 120 pontos.

2. Ordenar e desempatar

ORDER BY pontos DESC põe as pontuações mais altas primeiro. Acrescenta uma coluna como segundo critério para desempatar. Aplica LIMIT para obter só as primeiras linhas.

SELECT jogador, pontos
FROM rondas
WHERE nivel = 1
ORDER BY pontos DESC, jogador ASC
LIMIT 2;

Exercício. Prevê a ordem das duas primeiras linhas e confirma-a na sessão SQLite.

Solução comentada

Lia aparece primeiro e Teo em segundo. As duas rondas têm 120 pontos e o segundo critério ordena os nomes por ordem ascendente.

3. Agrupar resultados por jogador

GROUP BY jogador reúne as rondas de cada jogador. SUM(pontos) calcula o total de cada grupo. Usa HAVING para filtrar pelo total calculado.

SELECT jogador, SUM(pontos) AS total
FROM rondas
GROUP BY jogador
HAVING SUM(pontos) >= 200
ORDER BY total DESC, jogador ASC;

Exercício. Que jogador passa a aparecer quando baixas o mínimo para 190?

Solução comentada

Teo passa a aparecer com 190 pontos. Lia e Noa continuam na tabela, com 200 e 215.

Projeto prático — Classificação do torneio

Mostra os dois jogadores com maior total. Exige pelo menos duas rondas por jogador. Em caso de empate, ordena o nome alfabeticamente.

Consulta de referência 
SELECT jogador, SUM(pontos) AS total, COUNT(*) AS partidas
FROM rondas
GROUP BY jogador
HAVING COUNT(*) >= 2
ORDER BY total DESC, jogador ASC
LIMIT 2;

Com os dados iniciais, Noa fica em primeiro com 215 pontos e Lia segue com 200. Ambos têm duas rondas. Se acrescentares uma ronda de 500 pontos a um jogador novo, verifica que a classificação fica igual.

Questionário

1. Como filtras as rondas do nível 2?
2. Qual a opção que põe primeiro a pontuação mais alta?
3. Como selecionas jogadores com um total mínimo de 200 pontos?
