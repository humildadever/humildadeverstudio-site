Oficina Web

Cria a página de um minijogo. Usa HTML para montar o ecrã, CSS para definir o aspeto e JavaScript para contar os pontos.

Três desafios para começar

  1. HTML. Altera o título e o texto do botão. Conserva os identificadores placar e jogar, que ligam os elementos ao JavaScript.
  2. CSS. Muda a cor do fundo e do botão. Verifica se o texto continua legível.
  3. JavaScript. Altera pontos += 1 para pontos += 5, executa e confirma que dois cliques resultam em dez pontos.

Editor do minijogo

O rascunho fica neste navegador. Descarrega o HTML para guardar uma cópia e abri-la fora da oficina.
